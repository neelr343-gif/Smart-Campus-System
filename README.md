# OmniCampus – Smart College Portal

OmniCampus is an AI-powered smart college portal designed to improve campus life through intelligent academic assistance and visual AI.

## Features

* 📚 Notes and Formula Solver
* 🍽️ Cafeteria and Nutrition Analysis
* 🔍 Lost and Found Classification
* 🛠️ Campus Facility Defect Reporting
* 📅 Timetable and Poster Recognition
* 🤖 AI Campus Copilot
* 🗺️ Campus Map and Scheduling

## Technologies

* React
* TypeScript
* Vite
* Google Gemini AI

## Getting Started

### 1. Install dependencies

```bash
npm install --legacy-peer-deps
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the local URL

Open the URL displayed in your terminal.

## Project Goal

To create a smarter campus experience by combining academic support, campus services, and AI-powered image analysis.
